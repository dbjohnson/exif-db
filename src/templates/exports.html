Exports

An export copies the photos of the people chosen into a folder of its own, by year and month, with a website for looking through them. The website needs no server, so the folder can be shared as it is, on S3 or any other static host, with none of this app's managing in it.

New export

With a password, the website asks for it before showing anything, and its photos are kept in a folder named after it, so they can't be found without it. Everyone it's shared with uses the same one. A long password is safest, as anyone with the address can keep guessing.

Each export is the folder named under it in exports in the storage volume, which Download gives as a zip. Update brings an export up to date with the library, adding photos since named and taking away those since hidden or deleted. To share one on S3, copy its folder into a bucket with static website hosting on and index.html as its index document, such as with aws s3 sync exports/family-photos s3://your-bucket --delete, and let anyone read its files but not list them. Without a password, anyone with the address can see every photo in it.
