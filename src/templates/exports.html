Exports

An export copies photos into a folder of its own, by year and month, with a website for looking through them. The website needs no server, so the folder can be shared as it is, on S3 or any other static host, with none of this app's managing in it. To make one, select photos in Photos or any other list of them, and press Export in the selection bar.

Each export is the folder named under it in exports in the storage volume, which Download folder gives as a zip, website and all, for putting it somewhere else. Update makes an export again, leaving out photos since hidden or deleted. To share one on S3, copy its folder into a bucket with static website hosting on and index.html as its index document, such as with aws s3 sync exports/family-photos s3://your-bucket --delete, and let anyone read its files but not list them. Without a password, anyone with the address can see every photo in it.

To publish exports on Cloudflare R2 from here, set CLOUDFLARE_API_TOKEN to a token with Workers R2 Storage: Edit, and CLOUDFLARE_ACCOUNT_ID, in the app's environment.
